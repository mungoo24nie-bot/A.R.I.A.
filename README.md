
# A.R.I.A.

Autonomiczna Rozwijająca się Inteligencja Adaptacyjna

Eksperymentalna aplikacja Android rozwijana od podstaw.

## Założenia
- Rozmowa w języku polskim
- Lokalny model sztucznej inteligencji
- Trwała pamięć doświadczeń
- Stopniowe zdobywanie wiedzy
- Dostęp do internetu wyłącznie za zgodą użytkownika
- Możliwość działania bez internetu
